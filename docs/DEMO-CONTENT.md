## Theme Editor controls

Homepage sections now support:

- Image picker override
- Demo media selector
- Alt text field
- Editable headline/body/labels

## Production replacement path

In Shopify Theme Editor:

1. Open Homepage.
2. Select Hero Monolith.
3. Upload a production image in `Production image override`.
4. Leave demo selector as-is or set it to None.
5. Repeat for Product Proof and Collection Index blocks.

## IP note

Locked brand assets remain the official wordmark, iconic A, and red dash files.
