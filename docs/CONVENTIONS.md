# AKYRO MONOLITH OS — Conventions

## CSS

- Use tokens only.
- Use logical properties by default.
- Physical left/right only inside `direction.css` with paired RTL handling.
- No Arabic letter-spacing.
- Signal red is functional only.

## Liquid

- Storefront strings use translation keys.
- No invented product specs.
- Empty approved data renders controlled empty states.
- Snippets should not be kept orphaned unless deliberately documented.

## Assets

- Locked wordmark, iconic A, and red dash are source-controlled brand assets.
- Never redraw, recolor, stretch, mirror, or reinterpret AKYRO marks.
- Technical garment assets must not be mirrored in RTL.
