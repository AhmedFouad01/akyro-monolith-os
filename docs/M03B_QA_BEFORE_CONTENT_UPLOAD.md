# M03-B — QA Before Content Upload
Run before uploading any image or product content.

## Logo lock
[ ] No image file contains wordmark, iconic A, red dash, or any logo-like mark
[ ] No text, typography, UI, buttons, or screenshots inside imagery
[ ] Locked assets exist ONLY as Theme Editor uploads (Brand assets)
[ ] No CSS filters/recolor/stretch/mirror applied to any uploaded mark

## Data honesty
[ ] No fake GSM, measurements, batch codes (unless prefixed "Demo"), validation, supplier claims, launch dates, or limited-number scarcity
[ ] Pending states verified on a product with empty akyro.* fields

## Arabic / RTL
[ ] AR locale: layout mirrors, drawer inline-end, chevrons flip, no Arabic letter-spacing
[ ] SKUs/prices/counts render Latin and unshuffled inside Arabic text
[ ] New TE copy queued for Translate & Adapt after entry

## Dark / Light
[ ] Every target image checked on both modes at its real placement (see IMAGE_ASSET_PLAN_25 safe-mode column)
[ ] Hairlines and text remain legible over any background image

## Restricted phrase
[ ] "BUILT TO LAST" footer toggle OFF; phrase absent from all content and images
